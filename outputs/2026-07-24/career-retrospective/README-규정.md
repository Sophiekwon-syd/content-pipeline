- 대학원·유학·인턴·특별한 직무/직업 등 커리어 회고 → **#커리어회고** 태그 추가
- (주부·육아를 커리어로 재해석한 이 시리즈가 테마에 맞음)

## 유의사항 (리워드 관련 — 꼭 확인)

1. **[가장 중요] 자동화된 수단으로 작성한 글은 혜택 지급에서 제외될 수 있음.**
   → 이 폴더의 초안은 AI가 쓴 뼈대. 그대로 올리면 리워드 제외 위험.
   → 본인 목소리로 다시 쓰기 권장 (규정 준수 + 진정성).
   → 무성의/복붙/타인 콘텐츠 도용 글도 제외.
2. **2026-12-31까지 전체공개 + 검색허용 유지 필수.** 비공개·이웃공개 전환·삭제 시 리워드 불가.
3. 초상권·사생활 침해 주의 (사진에 타인 얼굴 나오면 주의).
4. **수익성 리뷰·홍보성 글, 캠페인 취지에 안 맞는 글 제외.**
   → 이 회고는 리뷰가 아니라 괜찮지만, 발행 시 쿠팡 등 제휴 링크는 넣지 말 것.
5. 당첨 시 네이버 ID 이메일로 안내, 개인정보 입력 기한 2026-08-25(화).
